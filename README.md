## Files

## Preview on your computer
1. Extract the ZIP file.
2. Open `index.html` in Chrome or another browser.

## Publish free with GitHub Pages
1. Sign in to GitHub: https://github.com/Rudr-python-git
2. Create a **new public repository** named `portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, and this README into the repository's root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then press **Save**.
7. Wait a few minutes. Your site should be available at:
   `https://rudr-python-git.github.io/portfolio/`

If that URL does not appear, check the Pages section for the published URL and any build status.

## Google Search visibility
Publishing a public site does not mean Google indexes it immediately. After publishing:
1. Open Google Search Console: https://search.google.com/search-console/
2. Add/verify your site property.
3. Submit the sitemap if you later add one, or request indexing for the homepage.
4. Use a clear title, description, and genuine project content. Search visibility may take time.
